A firewall that does the work, not just the logging

Small remote teams have no one to watch a security console. EdgeGuard takes over the routine decisions and only interrupts you when a human is needed.

Automatic triage

Rules on the Mac clear routine traffic instantly. Only unusual connections go to the AI, so nothing noisy reaches you and API usage stays low.

AI-made decisions

For each flagged connection, the AI returns a verdict: allow, block or ask, with a confidence score and a plain-language reason.

Self-managing block rules

Confirmed threats are blocked automatically. Rules expire on their own, so a wrong call never locks you out for long.

Audit trail for every action

Each decision is recorded with the evidence and the reason, so you can review what the firewall did and why.

You choose how much it does on its own

Start by watching. Move to automatic blocking when you trust the decisions.

Monitor

Observes and explains. Never blocks anything. The safe way to see what EdgeGuard would do on your Mac.

Suggest

Recommends a block with its reasoning and waits for your approval. This is the default mode.

Auto

Blocks high-severity threats by itself when the model is confident enough. Everything else still asks you.

Guardrails and privacy

An autonomous firewall must be careful. These limits are enforced in code and covered by unit tests.

  • Confidence threshold. Automatic blocks need a high-severity block verdict above the confidence you set.
  • Protected system processes. Core macOS services are never blocked automatically.
  • Fail safe. If the AI is unreachable or answers badly, EdgeGuard asks you and blocks nothing.
  • Temporary and reversible. Automatic blocks expire after one hour by default and can be undone.
  • Metadata only. The AI sees process name, remote host, port, protocol and byte count, never packet contents. User paths are removed and private addresses masked. Requests set store: false.
